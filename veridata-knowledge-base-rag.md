# Veridata Pro - Official Knowledge Base (RAG Source)

## 01. Company Overview & Positioning
**Company Name:** Veridata Pro
**Website:** veridatapro.com
**Founder:** Ugo Guazelli (Cloud Architect, 15+ years experience, 8+ years MuleSoft)
**Primary Offering:** Fractional architecture for B2B companies expanding into US and European markets. Veridata Pro clears technical security hurdles that block revenue, without the overhead of a full-time hire.
**Target Markets:** LatAm scale-ups, B2B companies closing enterprise deals, companies with legacy systems they cannot replace, and companies needing cyber insurance compliance.
**Core Methodology:** The "Strangler Fig" approach. Veridata wraps existing legacy infrastructure with an enterprise-grade security layer. This guarantees *zero code changes* and zero disruption to the client's current applications.
**Infrastructure Model:** 100% Single Tenant. Client data never lives on shared infrastructure.

## 02. Service Pillar 1: The Shield (Cybersecurity)
This pillar focuses on making LatAm and B2B companies contract-ready for US/EU enterprise buyers by providing audit-ready security infrastructure.

### The Shield Packages and Pricing
1. **Foundation Plan**
   - **Price:** $700 / month (Flat monthly retainer - no per-seat fees)
   - **Target Audience:** B2B companies selling to corporations or international markets.
   - **Features Included:**
     - Managed MFA (Email & Cloud)
     - AI Endpoint Protection (24/7)
     - Anti-Ransomware Backups
     - Vulnerability Monitoring
     - SSO for legacy apps (zero code changes)
     - Identity architecture design
     - Attack surface management
     - Vendor questionnaire support
     - vCISO Lite Assessments

2. **Transform Plan**
   - **Price:** $3,000 / month (Flat monthly retainer - scoped to compliance goals)
   - **Target Audience:** Fintech, healthtech, SaaS requiring SOC 2 / ISO 27001.
   - **Features Included:**
     - Everything in Foundation
     - Zero-trust architecture
     - SOC 2 / ISO 27001 preparation
     - MDR (Human Analysts 24/7)
     - Formal audit representation

### Productized Deployment: VeriGate
- **Price:** $3,000 to $5,000 one-time setup fee. (Included in Transform retainer).
- **Description:** A rapid Strangler Fig deployment of APISIX + Zitadel on AWS or GCP.
- **Speed:** Deploys an enterprise-grade API gateway and identity layer in under 48 hours for urgent vendor security reviews.

## 03. Service Pillar 2: Systems Integration Architecture (The Engine)
This pillar focuses on enterprise API orchestration, connecting legacy ERP, CRM, and WMS platforms into a unified ecosystem to eliminate manual data entry.

### Engagement Model
Every integration engagement begins with a **Paid Architectural Blueprint**.
- **Blueprint Price:** $1,500.
- **Details:** Veridata maps the systems, identifies integration gaps, and delivers an architectural plan before writing code. The $1,500 fee is fully credited toward the total project execution cost.

### Integration Packages and Tools
1. **API Gateway & High Availability**
   - **Price:** Starting at $2,000 + $200 / month retainer.
   - **Features Included:** API architecture blueprint, configured and active gateway, security and rate limit policies, monitoring dashboard.

2. **Event-Driven Architecture**
   - **Price:** Starting at $3,000.
   - **Details:** Replaces fragile point-to-point integrations with a resilient event-based system.
   - **Features Included:** Event architecture design, full migration plan, implementation, and knowledge transfer to the client team.

**Primary Tooling:** MuleSoft (for enterprise SLA demands), APISIX (API Gateway), Hybrid Cloud & On-Prem deploying.

## 04. Frequently Asked Questions (Q&A Context)
**Question:** Does Veridata Pro charge per user for its cybersecurity services?
**Answer:** No. Veridata uses a flat monthly retainer model (e.g., $700/mo for Foundation) without per-seat or per-user fees.

**Question:** How does Veridata secure legacy apps without breaking them?
**Answer:** Veridata employs the Strangler Fig architecture, utilizing API Gateways and identity providers (like APISIX and Zitadel) to create a protective security wrapper around the legacy application, ensuring zero code changes are required.

**Question:** What is VeriGate and how fast is it?
**Answer:** VeriGate is an urgent deployment service that implements an enterprise-grade API gateway and identity layer on AWS or GCP in under 48 hours, ideal for companies facing immediate vendor security reviews.

**Question:** How does Veridata start an integration project?
**Answer:** All API and integration projects begin with a $1,500 Paid Architectural Blueprint, which surveys the environment and plans the architecture before implementation. The fee credits toward the final build.

**Question:** Did Veridata discontinue Veri Rev Ops?
**Answer:** Yes, as of the 2026 website update, Veridata focuses exclusively on two core pillars: The Shield (Cybersecurity) and Systems Integration Architecture.
