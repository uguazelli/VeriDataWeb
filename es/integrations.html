La Tecnología

¿Qué es VeriGate?

Sus sistemas existentes, listos para enterprise en 48 horas — sin modificar su código.

dns

APISix — Capa de API Gateway

APISix se ubica frente a todos sus sistemas — aplicaciones cloud, ERPs legados, herramientas internas — y aplica seguridad en cada punto de entrada. Cada llamada de API se autentica, limita, registra y es auditable. Sus sistemas no cambian. Su exposición sí.

  • check Limitación de tasa y protección contra DDoS
  • check Gestión de claves de API y políticas de acceso
  • check Registro completo de solicitudes/respuestas para trazabilidad
  • check SSO para aplicaciones legadas sin modificar el código
fingerprint

Zitadel — Gestión de Identidad y Acceso

Zitadel es la columna vertebral de identidad. Gestiona SSO, MFA y control de acceso en todas sus aplicaciones — incluso las que nunca fueron diseñadas para autenticación moderna. Sus usuarios inician sesión una vez. Cada evento de acceso queda registrado centralmente y es controlable.

  • check SSO en todas las aplicaciones (cloud y on-prem)
  • check MFA resistente a phishing, forzado para todos
  • check Control de acceso basado en roles (RBAC)
  • check Gestión centralizada del ciclo de vida de usuarios

Relevancia para la Auditoría

Cómo la seguridad de API responde directamente al cuestionario de su comprador.

Las preguntas que le hace su comprador no son abstractas. Se mapean directamente a los controles que VeriGate implementa.

SOC 2 CC6 Controles de Acceso Lógico y Físico

"¿Exige MFA para todos los usuarios que acceden a sus sistemas?"

Zitadel impone MFA resistente a phishing en la capa de identidad — en todas las aplicaciones, incluidas las legadas que nunca lo soportaron de forma nativa. La respuesta se convierte en: sí, impuesto, gestionado centralmente, auditable.

ISO 27001 A.9 Gestión de Control de Acceso

"¿Cuenta con un sistema centralizado de gestión de identidad?"

Zitadel es su proveedor de identidad centralizado. El aprovisionamiento, desaprovisionamiento, asignación de roles y revisiones de acceso se gestionan desde un solo lugar — con registros de auditoría para cada acción.

NIST AC-2 Gestión de Cuentas

"¿Mantiene registros de quién accedió a qué y cuándo?"

APISix captura cada llamada de API — usuario autenticado, marca de tiempo, recurso accedido, acción realizada. Zitadel registra cada evento de autenticación. Juntos producen una pista de auditoría completa y exportable.

Cuestionario de Proveedor Revisión Típica de Seguridad Enterprise

"¿Tiene una política de seguridad de API y un inventario documentado de APIs?"

APISix le brinda un inventario vivo de APIs con políticas de seguridad aplicadas a cada ruta. Ugo documenta la configuración en un formato que el equipo de seguridad de su comprador puede revisar y aceptar.
