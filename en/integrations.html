Audit Relevance

How API security directly answers your vendor questionnaire.

The questions your buyer is asking are not abstract. They map directly to the controls VeriGate puts in place.

SOC 2 CC6 Logical & Physical Access Controls

"Do you enforce MFA for all users accessing your systems?"

Zitadel enforces phishing-resistant MFA at the identity layer — across every app, including legacy ones that never supported it natively. The answer becomes: yes, enforced, centrally managed, auditable.

ISO 27001 A.9 Access Control Management

"Do you have a centralized identity management system?"

Zitadel is your centralized identity provider. User provisioning, deprovisioning, role assignment, and access reviews are all managed from one place — with audit logs for every action.

NIST AC-2 Account Management

"Do you maintain logs of who accessed what, and when?"

APISix captures every API call — authenticated user, timestamp, resource accessed, action taken. Zitadel logs every authentication event. Together they produce a complete, exportable audit trail.

Vendor Questionnaire Typical Enterprise Security Review

"Do you have an API security policy and a documented API inventory?"

APISix gives you a living API inventory with security policies applied to each route. Ugo documents the configuration in a format your buyer's security team can review and accept.
