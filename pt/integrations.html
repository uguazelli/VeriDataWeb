A Tecnologia

O que é o VeriGate?

Os seus sistemas existentes, prontos para enterprise em 48 horas — sem mexer no código.

APISix — Camada de Gateway de API

O APISix fica na frente de todos os seus sistemas — aplicações cloud, ERPs legados, ferramentas internas — e aplica segurança em cada ponto de entrada. Cada chamada de API é autenticada, limitada por taxa, registrada e auditável. Os sistemas não mudam. A exposição deles muda.

  • check Limitação de taxa e proteção contra DDoS
  • check Gerenciamento de chaves de API e políticas de acesso
  • check Log completo de requisições/respostas para trilhas de auditoria
  • check SSO para aplicações legadas sem alterar o código
fingerprint

Zitadel — Gerenciamento de Identidade e Acesso

O Zitadel é a espinha dorsal de identidade. Ele gerencia SSO, MFA e controle de acesso em todos os seus aplicativos — inclusive os que nunca foram projetados para autenticação moderna. Seus usuários fazem login uma vez. Cada evento de acesso é registrado centralmente e controlável.

  • check SSO em todos os aplicativos (cloud e on-prem)
  • check MFA resistente a phishing, forçado para todos
  • check Controle de acesso baseado em papéis (RBAC)
  • check Gerenciamento centralizado do ciclo de vida de usuários

SOC 2 CC6 Controles de Acesso Lógico e Físico

"Você exige MFA para todos os usuários que acessam seus sistemas?"

O Zitadel força MFA resistente a phishing na camada de identidade — em todos os aplicativos, incluindo os legados que nunca suportaram isso nativamente. A resposta vira: sim, forçado, gerenciado centralmente, auditável.

ISO 27001 A.9 Gestão de Controle de Acesso

"Você tem um sistema centralizado de gerenciamento de identidade?"

O Zitadel é o seu provedor de identidade centralizado. Provisionamento, desprovisionamento, atribuição de papéis e revisões de acesso são gerenciados em um único lugar — com logs de auditoria para cada ação.

NIST AC-2 Gerenciamento de Contas

"Você mantém registros de quem acessou o quê, e quando?"

O APISix captura cada chamada de API — usuário autenticado, timestamp, recurso acessado, ação realizada. O Zitadel registra cada evento de autenticação. Juntos, produzem uma trilha de auditoria completa e exportável.
